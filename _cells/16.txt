### 3.3 Assembling the EDA Graph with Conditional Routing

The graph structure is:

```
START -> parse_spec -> select_topology -> generate_netlist -> run_simulation -> evaluate_ppa
                                                ^                                    |
                                                |                                    v
                                                +--- (status == "running") <-- should_continue?
                                                                                     |
                                                                    (converged) -> generate_layout -> END
                                                                    (failed) -> END
```

The critical routing function:

$$
r(s) = \begin{cases}
\texttt{generate\_netlist} & \text{if } s.\text{status} = \text{``running''} \\
\texttt{generate\_layout} & \text{if } s.\text{status} = \text{``converged''} \\
\texttt{END} & \text{if } s.\text{status} = \text{``failed''}
\end{cases}
$$
