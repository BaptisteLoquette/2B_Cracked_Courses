## 7. Human-in-the-Loop Integration

### 7.1 Approval Gates in EDA

Certain design decisions are too critical to automate without human oversight:

- **Topology selection** — a senior designer must approve the architecture before sizing begins.
- **Final sign-off** — before tapeout, a human reviews the PPA metrics and layout.

LangGraph supports this via `interrupt_before` and `interrupt_after`, which pause graph execution at a specified node and wait for human input.

### 7.2 Execution Model with Interrupts

$$
\text{START} \to n_1 \to n_2 \to \underset{\text{INTERRUPT}}{\boxed{n_3}} \xrightarrow{\text{human resumes}} n_4 \to \text{END}
$$

The interrupt mechanism:
1. Graph executes normally until it reaches the interrupt node.
2. Execution **pauses** and the current state is checkpointed.
3. An external process (human / dashboard) reviews the state.
4. The human optionally **modifies** the state via `update_state()`.
5. Graph execution **resumes** from the interrupted point.
